# 组件开发文档

## 1. 广告组件 (AdContainer)

### 1.1 组件介绍
`AdContainer` 是一个跨平台的广告容器组件，支持在H5、Android和iOS平台上展示不同类型的广告。

### 1.2 组件属性
| 属性名 | 类型 | 必填 | 默认值 | 说明 |
|-------|------|------|--------|------|
| adType | string | 是 | 'banner' | 广告类型：banner/interstitial/reward |
| adId | string | 是 | - | 广告位ID |
| adData | object | 否 | {} | 广告数据 |
| adStyle | object | 否 | {} | 广告样式 |

### 1.3 组件事件
| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| onLoad | 广告加载成功 | event |
| onError | 广告加载失败 | error |
| onClick | 广告被点击 | event |
| onClose | 广告被关闭 | - |

### 1.4 使用示例
```vue
<template>
  <ad-container
    adType="banner"
    :adId="topBannerId"
    :adData="topBannerData"
    @onLoad="handleAdLoad"
    @onClick="handleAdClick"
  />
</template>

<script lang="ts" setup>
import { ref } from 'vue'

const topBannerId = ref('your_ad_id')
const topBannerData = ref({
  imageUrl: 'https://example.com/ad.jpg',
  linkUrl: 'https://example.com/promotion'
})

const handleAdLoad = (e: any) => {
  console.log('广告加载成功', e)
}

const handleAdClick = (e: any) => {
  console.log('广告被点击', e)
}
</script>
```

## 2. 视频播放器组件 (VideoPlayer)

### 2.1 组件介绍
跨平台视频播放器组件，支持多种视频格式和播放控制。

### 2.2 组件属性
| 属性名 | 类型 | 必填 | 默认值 | 说明 |
|-------|------|------|--------|------|
| src | string | 是 | - | 视频源地址 |
| poster | string | 否 | - | 视频封面图 |
| autoplay | boolean | 否 | false | 是否自动播放 |
| controls | boolean | 否 | true | 是否显示控制栏 |

### 2.3 组件事件
| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| onPlay | 开始播放 | - |
| onPause | 暂停播放 | - |
| onEnded | 播放结束 | - |
| onTimeUpdate | 播放进度更新 | {currentTime, duration} |

## 3. 轮播图组件 (Swiper)

### 3.1 组件介绍
支持多端的图片轮播组件，可用于展示广告、推荐内容等。

### 3.2 组件属性
| 属性名 | 类型 | 必填 | 默认值 | 说明 |
|-------|------|------|--------|------|
| list | array | 是 | [] | 轮播项列表 |
| autoplay | boolean | 否 | true | 是否自动播放 |
| interval | number | 否 | 3000 | 自动播放间隔 |
| duration | number | 否 | 500 | 滑动动画时长 |

### 3.3 组件事件
| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| onChange | 轮播切换 | index |
| onClick | 点击轮播项 | item |

## 4. 组件开发规范

### 4.1 命名规范
- 组件文件名：PascalCase
- 组件名称：PascalCase
- 属性名：camelCase
- 事件名：camelCase，以on开头

### 4.2 目录结构
```
components/
├── ad/
│   ├── AdContainer.vue
│   └── types.ts
├── player/
│   ├── VideoPlayer.vue
│   └── types.ts
└── common/
    ├── Swiper.vue
    └── types.ts
```

### 4.3 类型定义
```typescript
// components/ad/types.ts
export interface AdProps {
  adType: 'banner' | 'interstitial' | 'reward';
  adId: string;
  adData?: Record<string, any>;
  adStyle?: Record<string, any>;
}

export interface AdEvents {
  onLoad: (event: any) => void;
  onError: (error: any) => void;
  onClick: (event: any) => void;
  onClose: () => void;
}
```
