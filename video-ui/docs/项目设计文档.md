# 视频应用项目设计文档

## 1. 项目概述

### 1.1 项目简介
本项目是一个基于 Uni-app 开发的跨平台视频应用，支持 H5、Android 和 iOS 三端，采用一套代码实现多端发布。

### 1.2 技术栈
- Uni-app - 跨平台开发框架
- Vue 3 - 开发语言
- TypeScript - 类型支持
- Pinia - 状态管理
- uView UI - UI组件库
- Vite - 构建工具

## 2. 项目结构

```
video-app/
├── src/
│   ├── api/                 # API接口
│   ├── static/             # 静态资源
│   │   ├── images/        # 图片资源
│   │   └── icons/         # 图标资源
│   ├── components/         # 公共组件
│   │   ├── layout/        # 布局组件
│   │   ├── player/        # 播放器组件
│   │   └── common/        # 通用组件
│   ├── pages/             # 页面文件
│   │   ├── index/        # 首页
│   │   ├── category/     # 分类页
│   │   ├── player/       # 播放页
│   │   └── user/         # 用户中心
│   ├── store/             # 状态管理
│   ├── utils/             # 工具函数
│   ├── styles/            # 全局样式
│   └── platforms/         # 平台特定代码
│       ├── app/          # 原生App特定
│       ├── h5/          # H5特定
│       └── mp/          # 小程序特定
├── pages.json            # 页面路由配置
├── manifest.json         # 应用配置
└── uni.scss             # 全局样式变量
```
